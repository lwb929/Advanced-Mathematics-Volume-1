# 高等数学（同济第八版·上册）自学整理

把教材整理成便于检索、阅读和自学的 Markdown 知识库，包含第一至七章、附录、原书页面、概念索引，以及课后习题的解析答案与辅助配图。

## 这份整理是怎样做出来的

这份整理最初是**小米 OCR 模型在 E5、16 GB 内存平台上连续跑了一整个晚上**的产物。在此基础上，先由 **GLM 进行初次视觉修补**，再由 **Codex 补充解析答案**、解题说明和必要配图，逐步形成现在的自学版本。

| 阶段 | 工具与工作 |
| --- | --- |
| 教材识别 | 小米 OCR 模型；在 E5、16 GB 内存平台上运行了一整个晚上，得到初始转写 |
| 初次视觉修补 | GLM 对识别结果进行初步视觉修补 |
| 解析与自学补充 | Codex 编写课后习题解析答案、关键步骤说明、折叠辅助注释与配图，并对照本地扫描核查发现的题式差异 |

教材转写、历史批注与新增讲解在文档中分开标明。OCR 和视觉修补可能仍有遗漏；新增答案也需结合原题条件阅读，不能把本库视为已经逐字校订的教材原文。

## 从哪里开始

- [教材首页](00-首页.md)：按章节或当前问题进入。
- [课后习题详细解答](课后习题详细解答.md)：第一至七章共 52 组、578 道大题，小题沿用原编号。
- [习题配图索引](习题详解/配图索引.md)：查看已接入解答的原书题图局部与新增辅助图。
- [编写与核对说明](习题详解/编写与核对说明.md)：查看覆盖范围、扫描差异、核对方式与未裁决的题图冲突。
- [自学入口与探索约定](自学入口与探索约定.md)：查看具体提示、可选练习及返回主线的方法。

## 阅读与链接

推荐搭配 **DeepTutor** 使用，辅助教材学习，使用效果更好。

推荐使用 **Obsidian** 查看和预览，预览效果更好，能够更完整地呈现双向链接、公式、折叠注释和 Canvas。将本目录加入已有的库后，从 `00-首页.md` 开始；用普通 Markdown 阅读器也能查看正文和新增 PNG 配图，但 `[[双向链接]]`、折叠注释等语法的显示取决于阅读器。

Markdown 中的多数双向链接按文件名定位。Canvas 的文件节点则按 Obsidian 库根目录定位，当前节点路径含 `高等数学-同济八版上册/` 前缀。若更改文件夹名称或改为把本目录直接作为独立库打开，需要在 Canvas 中相应调整文件节点的关联路径。

遇到公式、题号或图形与答案不一致时，先查看题旁核对说明，再回到对应的原书页面。习题 1-3 第 3 题有三项判断涉及原图与书末答案冲突，已明确标注，未强行给出确定结论。
