# 📂 路径与链接说明

本库所有链接已做**移动无损**处理：

## Markdown 链接（70 个文件）
- 全部使用**最短文件名形式** `[[1-2-数列的极限]]`，Obsidian 按文件名解析
- 把本文件夹整体拷贝/移动到任何库的任何位置，MD 链接**都不会断**

## Canvas 画布（2 个）
- Canvas 格式限制：`file` 节点必须写**库根相对路径**，无法按名解析
- **作为独立库使用**（Obsidian → 打开文件夹作为库）：无需任何操作
- **放入现有库的子目录**（如 `我的库/Docs/高等数学-同济八版上册/`）：运行一次
  ```bash
  python3 fix_canvas_prefix.py "Docs/高等数学-同济八版上册"
  ```
  （前缀 = 本文件夹相对库根的路径，末尾不带斜杠）

## 依赖
- 仅需 Obsidian **v1.1+**（Canvas 为原生功能，MathJax 为核心功能）
- 无需任何社区插件
